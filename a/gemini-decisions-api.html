Gemini Decisions API 发布：一次最多提 1000 个判断题

Google DeepMind 推出 Gemini Decisions API，由新模型 Gemini Decision 1 驱动，支持 yes/no、多选题与按标准打分的问题，单次请求最多 1000 个问题，上下文 256k，端到端 150 到 250 毫秒。

Philipp Schmid（@_philschmid）· 原帖 2026-11-11T18:15:42+00:00 · 收录 2026-11-12T08:35:00+08:00

Philipp Schmid 宣布推出 Gemini Decisions API，一个专门做 yes/no、多选题与按标准打分的问题的接口，背后是新模型 Gemini Decision 1。

一次 1000 个问题，150 到 250 毫秒出结果

接口一次请求最多可以提 1000 个问题，上下文是 256k。端到端耗时 150 到 250 毫秒。每个答案都带一个置信度分数。

输入覆盖文本、图片、音频、视频与 PDF

输入支持文本、图片、音频、视频和 PDF。定价是每 100 万输入 token 0.10 美元，输出免费。

Excited to announce the Gemini Decisions API, a new API for yes/no, multiple choice, and rubric questions, powered by our new Gemini Decision 1 model.

🖼️ Text, images, audio, video, PDFs input support
