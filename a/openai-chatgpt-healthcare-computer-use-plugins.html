ChatGPT for Healthcare 再推进：更强的计算机使用 Agent 与 20 多个医疗插件

OpenAI 宣布 ChatGPT for Healthcare 继续推进：计算机使用 Agent 更强、临床回答更扎实，新增 20 多个医疗插件，Abridge、Ambience、Cigna 与 CVS Health 已把模型用在事先授权、转诊与出院规划上。

OpenAI 宣布 ChatGPT for Healthcare 继续推进：计算机使用 Agent 能力更强，临床回答更扎实，还新增了 20 多个医疗插件。官方文章链接附在帖子末尾，地址是 openai.com/index/advancing-computer-use-for-healthcare-teams/。

Abridge、Ambience、Cigna 与 CVS Health 已在用

Abridge、Ambience AI、Cigna、CVS Health 等医疗机构正在把模型用在事先授权、转诊、出院规划和患者外联上。帖子点名了这四家，另说还有其他领先医疗机构。

定位：把医学证据接到团队已在用的工具里

按 OpenAI 的说法，这些进展把医学证据和实际帮助接到团队已经在用的工具上，目的是让团队少花时间在系统里周转，多花时间照顾病人。这是发布者的表述，帖子没有给出具体效果数据。
