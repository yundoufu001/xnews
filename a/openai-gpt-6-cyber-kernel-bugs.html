GPT-6 Cyber 一轮验证 948 个 Linux 内核提权漏洞，还生成了补丁

OpenAI 称，在一轮运行里，GPT-6 Cyber 帮助验证了 948 个可能导致本地提权的 Linux 内核漏洞，并为评审生成了补丁。研究员 Clint Gibler 与 Kyle Bot（@ky1ebot）分享了发现，以及他们如何与维护者合作把修复推向上游。

OpenAI（@OpenAI）· 原帖 2026-11-23T23:25:45+00:00 · 收录 2026-11-25T08:35:00+08:00

OpenAI 说，在一轮运行里，GPT-6 Cyber 帮助验证了 948 个 Linux 内核漏洞，这些漏洞可能让人拿到本地 root 权限。模型还为评审生成了补丁。

一轮运行，948 个漏洞

帖子强调的数字只来自一轮运行：948 个可能导致本地提权的 Linux 内核漏洞得到验证，补丁已经生成，交给评审看。帖子没有说这些补丁已经合并，也没有给出合并数量。

研究员和维护者一起把修复推向上游

OpenAI 研究员 Clint Gibler 与 Kyle Bot（@ky1ebot）分享了他们的发现，以及他们如何与维护者合作，把修复推向上游。研究的完整内容见 OpenAI 的文章《A Thousand Fewer Paths to Root》，链接在文末原文里。

948 这个数字讲的是一轮运行里的验证量

948 这个数字讲的是一轮运行里的验证量，不是漏洞总数，也不是已修复数量。把它当成一次验证能力的展示更贴切：模型能在一轮里筛出这么多可验证的候选漏洞，并产出可供评审的补丁。
