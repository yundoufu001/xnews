Box 实测 Gemini 4 Hydrogen：准确率高 5 个百分点，用时不到一半

Box 用 Box AI Complex Work Eval 早期测试 Gemini 4 Hydrogen：准确率比 Gemini 3.8 Flash 高 5 个百分点，用时不到一半，典型任务 token 用量少约 12%，不久后进入 Box AI Studio。

Aaron Levie（@levie）· 原帖 2026-11-12T18:33:00+00:00 · 收录 2026-11-14T08:32:00+08:00

Box CEO Aaron Levie 说，Box 正在用自家的 Box AI Complex Work Eval 对 Gemini 4 Hydrogen 做早期测试，结果让他觉得这是个不小的进展。按他的说法，对快速模型来说，这是一次明显的跃升。

准确率高 5 个百分点，用时不到一半

测试数据显示，Hydrogen 的准确率比 Gemini 3.8 Flash 高 5 个百分点。Levie 认为，只看准确率这一项就已经是不错的提升。更关键的是速度和用量：Hydrogen 完成任务的用时不到 Flash 的一半，典型任务的 token 用量还少约 12%。

测的是真实企业文档工作

这套评测不跑通用基准。它让 Box Agent 以 Hydrogen 为模型，处理一系列模拟真实工作的复杂任务，涉及金融、咨询、生命科学等行业的企业文档。Levie 的判断是，Hydrogen 会成为很多高效但复杂任务的合适选择。

英文原文（完整保留）

Ok this is a big deal. We’ve been testing Gemini 4 Hydrogen in early access with the Box AI Complex Work Eval, and it’s a serious jump for fast models.

Hydrogen is 5 percentage points better in accuracy than Gemini 3.8 Flash. That alone would be a great boost in capability, but possibly more importantly it did the tasks in less than half the time with about 12% fewer tokens on a typical task.

For this eval, we give the Box Agent Hydrogen as a model for a series of complex tasks that represent real world work with enterprise documents across finance, consulting, life sciences, and other industries. Hydrogen will be a great model for a lot of efficient but complex tasks across these fields.

Gemini team is definitely cooking. Hydrogen will be rolling out in the Box AI Studio shortly so any customer can build a custom agent with it.
