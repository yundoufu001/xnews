Vercel 发布 Workflow SDK 5：首步更快，耐久日志可复用于任意 Agent 框架

Vercel 发布 Workflow SDK 5 与 Vercel Workflows：首步与步间等待大幅缩短，加密与安全加码，底层耐久日志独立为 durable-harness，可供任何 Agent 框架复用。

Guillermo Rauch（@rauchg）· 原帖 2026-11-13T16:23:16+00:00 · 收录 2026-11-15T08:30:00+08:00

Guillermo Rauch 宣布 Vercel 发布 Workflow SDK 5 与 Vercel Workflows。他在帖子里称，这是 Agent 方向上的一大步。

首步更快，步与步之间的等待更短

帖子列出的第一项改进是速度：“time to first step”与“time between steps”都有大幅提升。也就是说，工作流启动后迈出第一步更快，每一步之间的等待也更短。

加密与安全加码，可靠性经过大规模验证

第二项是安全：团队在加密与安全上加了码。第三项是可靠性，帖子的说法是，整个系统的可靠性已经在很大规模下得到验证，团队打磨了许多细微之处，也演练了不少灾难恢复场景。

耐久日志独立出来，任何 Agent 框架都能复用

最后一项是架构上的变化：底层的耐久日志现在可以复用到任何 Agent 框架里，由此诞生了 durable-harness。帖子没有给出具体的性能数字，上面几项都是作者的定性描述。
