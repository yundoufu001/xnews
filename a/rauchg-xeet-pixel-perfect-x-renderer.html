Rauch 发布 xeet：Rust 写成的像素级 X 帖子渲染器，约 1 毫秒出图

Guillermo Rauch 发布 xeet：Rust 与 WebAssembly 写成的 X 帖子渲染器，不依赖浏览器、网络与系统字体，约 1 毫秒出图，复现 Blink 与 HarfBuzz 的排版细节，靠 Oracle 核对数万条规则来自我验证。

Guillermo Rauch（@rauchg）· 原帖 2026-11-16T04:27:37+00:00 · 收录 2026-11-17T08:50:00+08:00

Vercel CEO Guillermo Rauch 发布了 xeet，一个用 Rust 与 WebAssembly 写成的 X 帖子渲染器，项目地址是 xeet-rs.vercel.app。按他的说法，xeet 不依赖浏览器、网络、文件系统和系统字体，渲染过程是封闭的，输出像素级还原帖子外观。

约 1 毫秒出图，比浏览器截图快 100 到 1000 倍

帖子给出的数字是，渲染一张帖子图片大约 1 毫秒，Jack Dorsey 的第一条帖子 "setting up my twttr" 只要 0.4 毫秒。Rauch 称，这个速度比启动浏览器再截图快 100 到 1000 倍，准确度相当。

复现 Blink 与 HarfBuzz 的排版细节

xeet 复现了 Blink 与 HarfBuzz 的文本塑形、1/64 像素行断、RTL 双向文本、28 个 Chirp 字体子集，以及 CJK、数学符号、表情的回退规则和 "Show more" 的展开规则。Rauch 说，这种细节量靠人工工程师几乎不可能完成。

自验证仓库：Oracle 核对数万条排版规则

xeet 按 "autorepo" 结构组织：一个 Oracle 启动 Chrome，核对数万条文本排版规则；CI 金丝雀跟踪原版的演进，给 Agent 提交带签名的 PR。Rauch 把这套做法称为 "verification engineering"，也就是围绕验证来设计。

Rauch 还说，X 是全球公共广场，媒介本身就是信息，能在发帖前预览最终效果，对人和 Agent 都有用。想试的人，入口就是 xeet-rs.vercel.app。

英文原文（完整保留）

Introducing 𝚡𝚎𝚎𝚝: http://xeet-rs.vercel.app.

A hermetic, pixel-perfect X post renderer in safe Rust / wasm. Zero browser, network, filesystem, system fonts. Renders a post to PNG in ~1ms (and 0.4 ms for @jack's "setting up my twttr" 😁).

X is the global town square, and the medium is the message. Being able to preview what things will look like before posting is great for both humans and agents.

Rendering with xeet is is 100x-1000x faster than booting up a browser and taking a screenshot, yet it's just as accurate.

It reproduces Blink & HarfBuzz text shaping, 1/64px line breaking, RTL bidi, 28 Chirp font subsets, CJK/Math/Emoji fallbacks, "Show more" rules, etc. It's the kind of thing that would be wildly impractical, if not impossible, for a human engineer to pull off.

Except 𝚡𝚎𝚎𝚝 is structured as an "autorepo." An oracle boots up Chrome, and verifies tens of thousands of text layout rules. A CI canary then watches the evolution of the original, and files signed PRs for agents to act on. It was conceived from the ground up around 'verification engineering', and the result speaks for itself.

Enjoy!
