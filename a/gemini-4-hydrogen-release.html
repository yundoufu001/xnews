Gemini 4 Hydrogen 上线：Terminal-Bench 4.0 得分 57%

Google DeepMind 的 Gemini 4 Hydrogen 上线 Google AI Studio 与 Gemini API，Terminal-Bench 4.0 得分 57%，思考档位四档，定价 1.50 美元和 7.50 美元，AI Studio 与 API 提供免费档。

Philipp Schmid（@_philschmid）· 原帖 2026-11-12T18:02:47+00:00 · 收录 2026-11-13T08:40:00+08:00

Philipp Schmid 宣布，Gemini 4 Hydrogen 即日起在 Google AI Studio 和 Gemini API 上线。这是 Google DeepMind 的新模型，定位是日常快速执行。

速度见长，Terminal-Bench 4.0 得分 57%

帖子列出四项指标。在 Artificial Analysis 的评测里，Hydrogen 的成绩超过 Argon。Terminal-Bench 4.0 得分 57%。思考档位有 low、medium、high、xhigh 四档。定价标为 1.50 美元和 7.50 美元，Google AI Studio 和 Gemini API 提供免费档。

作者自述：日常主力，配 Carbon 当子代理

按 Schmid 自己的说法，Hydrogen 已经成了他日常工作的主力，适合日常快速执行和研究循环，配 Carbon 当子代理效果很好，尤其擅长从写代码到跑测试的快速循环。这里要分清，这是作者个人的使用感受，不是独立评测结论。

同步向付费订阅用户开放

Hydrogen 也在向 Google AI Pro 和 Ultra 的付费订阅用户开放，覆盖 Antigravity、Gemini App、Google Search 和 Google Cloud。
